# Release readiness

- [ ] Scope and acceptance criteria approved
- [ ] Working tree and branch verified
- [ ] Focused tests pass
- [ ] Standard lint/typecheck/test/build checks pass or are documented as unavailable
- [ ] Diff reviewed for correctness, security, compatibility, and secrets
- [ ] Breaking changes and migrations explicitly called out
- [ ] Documentation/changelog updated where needed
- [ ] Final user approval received before merge, publish, or release
