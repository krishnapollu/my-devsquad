# Release

Verify branch, remotes, diff, tests, and repository release conventions. Never force-push, rewrite history, delete branches, publish packages, or release production artifacts without explicit approval. Prepare a concise PR/release summary. GitHub/Slack/email notifications are optional integrations, not required capabilities; without an authorized connector, provide copy-ready text only.
