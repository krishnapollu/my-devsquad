# Implementation

Read the approved spec and current state first. Inspect only files relevant to the change, following repository-local instructions. Prefer existing patterns over introducing dependencies. Make atomic edits, preserve unrelated changes, and update the checkpoint after meaningful milestones. Before handing off, summarize changed files, behavior, risks, and validation still needed.
