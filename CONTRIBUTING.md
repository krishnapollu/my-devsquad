# Contributing

Keep skills focused on recognizable user goals. Prefer concise instructions and progressive disclosure through templates or references. Do not add a server or external dependency unless it provides a capability that cannot safely be performed locally.

Before opening a change:

1. Run `python3 scripts/validate.py`.
2. Run the available tests.
3. Check that manifests parse and every skill has valid frontmatter.
4. Explain behavior, safety implications, and any unsupported integration honestly.

Use small commits and preserve unrelated changes. Never include credentials, tokens, or private repository content in examples.
